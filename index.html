IRIS-AI

Intelligent Remote-sensing Infrared Interpretation Suite

An end-to-end AI pipeline that transforms raw infrared satellite imagery into high-resolution, colorized, semantically annotated, and human-interpretable outputs.

How it works

Five-Stage Deep Learning Pipeline

Every infrared image flows through a sequential, modular pipeline. Each stage is independently testable and replaceable — the UNet++ GAN colorizer is treated as a black-box inference engine.

Features

What IRIS-AI Does

⚡

Zero VRAM Duplication

A ModelManager singleton loads each neural network exactly once, preventing GPU OOM errors across five simultaneous models.

🎨

UNet++ IR Colorization

Nested dense skip pathways bridge the semantic gap between encoder and decoder, producing accurate texture recovery in roads, water, and vegetation.

🔍

×4 Super Resolution

Real-ESRGAN reconstructs spatial detail lost during IR capture, producing sharp high-resolution imagery from low-res thermal inputs.

🗺️

Semantic Land Cover Mapping

FastSAM identifies and colour-codes roads, buildings, water bodies, vegetation, and bare land without manual annotation at inference time.

📄

Analyst PDF Reports

ReportLab-generated professional PDF reports combine all pipeline outputs with a natural-language BLIP scene interpretation.

🖥️

Premium Streamlit Dashboard

An 8-page dashboard for interactive inference, batch processing, comparison sliders, analytics, and ZIP export — no code required.

Get Started

Quick Start in 3 Steps

# 1. Clone and install
git clone https://github.com/vssanjay-11/ISRO-BAH-IRIS.git
pip install torch==2.1.2 torchvision==0.16.2 --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt

# 2. Download model weights
python download_weights.py

# 3. Launch the dashboard
streamlit run frontend/app.py
