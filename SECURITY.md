# Security Policy

## Supported Versions

Only the latest stable version of **IRIS-AI** is actively supported with security patches.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you identify a security vulnerability in this project, please report it privately to avoid exposing users to risk.

To report a vulnerability:
- Send an email to **security@example.com** with details.
- Include a description of the issue, step-by-step reproduction instructions, and any potential remediation.
- We will acknowledge receipt of your report within 48 hours and coordinate a patch release.
